# Deliverable J — Pilot Design and Success Metrics

## Pilot design

**Broker:** Kevin Osiga (already agreed to a free MVP for quote comparison; natural first candidate for document chasing).

**Duration:** 30–60 days (matches the objective of first paid client at $1,000–$2,000).

**Scope:** KYC/onboarding document chasing for Kevin's active cases only. Manual metric tracking during the pilot — no automation assumptions.

**Channels:** WhatsApp (primary) → SMS (fallback) → email, with phone-call escalation and exception queue (>7 days).

**What the pilot proves:**
1. Whether automated nudges actually reduce document-chase time vs. manual Excel/phone chasing.
2. Whether clients respond to secure upload links vs. prefer WhatsApp/email direct.
3. Whether Kevin is willing to pay $1,000–$2,000 (conversion from free MVP to paid).

## Success metrics

| Metric | Target | Measurement |
|--------|--------|-------------|
| First-time complete submission rate | Improve vs. Kevin's manual baseline | % of submissions with all required docs on first try |
| Average days from request to submission | Decrease vs. baseline | Days tracked per case |
| Cases reaching exception queue (>7 days) | Minimise | % of cases escalated to exception queue |
| Broker willingness to pay | $1,000–$2,000 | Kevin's indication at pilot end |
| Active cases managed | TBD | Count of cases in pilot |

If willingness-to-pay is below $1,000, the MVP price point or value proposition is revisited before building more.

## Pilot exit criteria
- All 8 acceptance tests (Deliverable G) pass.
- Kevin indicates willingness to pay within $1,000–$2,000 range.
- Document chase time measurably lower than manual baseline.
