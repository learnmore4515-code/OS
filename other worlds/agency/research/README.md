# AI Agency Research Knowledge Base

This is the persistent research knowledge base for the AI agency mission. It does NOT live in conversation context — it survives across sessions.

## Structure

| Path | Purpose |
|------|---------|
| `video-research-ledger.md` | Every source URL accounted for, with status and pointer to its research file |
| `videos/` | One research note per individual video |
| `creators/` | One note per creator, aggregating their videos |
| `topics/` | Thematic synthesis (niche, offers, acquisition, sales, fulfillment, pricing, tools, scaling, failures) |
| `evidence-matrix.md` | Major claims, which sources support/contradict them, evidence strength |
| `contradictions.md` | Conflicting advice preserved with conditional rules derived |
| `research-synthesis.md` | Cross-video synthesis of the full value chain |
| `CURRENT-RECOMMENDATION.md` | Current answer to "what should Kim do right now?" |
| `MASTER-AI-AGENCY-PLAYBOOK.md` | The final coherent path |
| `playbooks/` | Versioned playbooks (PLAYBOOK-v1, v2, …, CURRENT-PLAYBOOK) |
| `PLAYBOOK-AUDIT.md` | Mandatory audit before a playbook becomes recommended |

## Rule

A video is PROCESSED only when its actual content has been consumed and its substance extracted into its research file. Finding a title is not enough.
