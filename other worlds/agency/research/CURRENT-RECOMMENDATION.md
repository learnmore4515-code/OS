**Niche selection:** Use the 4-factor unfair-advantage audit in STRICT priority order:

## Current acquisition mechanism
**Warm network / referral-led FIRST (not cold outreach):**
1. Build a trust map: Google Sheet of 20 people where trust already exists (friends/family running businesses, past co-workers, managers, clients, community/Slack/Discord contacts, friends of friends); note industry, closeness, and client/intro/insight potential (Nate Herk 061).
2. Days 2–3: 5–10 warm, low-pressure, non-pitch discovery conversations ("I'm not trying to sell you anything. Could I just ask you a few questions about where things feel manual or annoying in your day-to-day?").
3. Days 4–5: Turn one conversation into a tiny FREE pilot — one small automation on the clearest painful task, one measured outcome, in exchange for honest feedback.
4. Days 5–6: Build a tiny MVP (simpler the better — goal is showing time saved, not impressive tech). Capture the client's own language about the problem and the win.
5. Day 7: No hard close — propose maintenance (keep it working, fix breaks, tweaks) or expansion (add 1–2 features). Ask for testimonial/referral only AFTER delivered proof.
6. Repeat the cycle multiple times before attempting cold outreach. Defer cold outreach and Upwork until after several proof cycles (Nate Herk 061).

## Current delivery mechanism
Done-for-you, phases: planning → building → reviewing → deploying → handing over (signing is prerequisite "phase 0") (Liam Ottley 007).
- Planning: identify needs/chatbot value; gather requirements (Q&A knowledge base, conversation flow, capture fields, conversion events)
- Building: Botpress nodes/transitions/messages/variables + custom code blocks; Stack AI via API for KB queries; fallback loop so bot never dead-ends; re-push conversion after every answer
- Reviewing: send testing URL; client stress-tests; batch feedback into ONE iteration round (not constant back-and-forth)
- Deploying: client creates Botpress account, adds builder as collaborator, builder transfers bot to client's account; client billed/responsible
- Handing over: bot lives on client's account; embed via web-chat script URL on client's website
**Tech stack:** Botpress + Stack AI via API + Figma (flow design) + custom code blocks (Liam Ottley 007).
