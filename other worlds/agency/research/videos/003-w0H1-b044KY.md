## What this video is actually about
A full-course beginner's guide by Liam Ottley (creator of Morningside AI and the Agentive platform) covering three chapters: (1) foundational understanding of what AI agents are and how they work under the hood, (2) four end-to-end AI agent build tutorials across four no-code platforms, and (3) a blueprint for monetizing AI agent building skills — education, consulting, and implementation services sold to small businesses. The video is creator-stated as drawing on two years of experience and over $5 million in revenue across his AI businesses.

## Key lessons
- An AI agent is a digital worker that can understand instructions and take actions to complete tasks — not just a chatbot that recites information.
- An agent has five parts: brain (LLM), prompting/instructions, memory, external knowledge (optional), and tools (what turns chatting into doing).
- In practice, builders focus on three "ingredients": knowledge, tools, and prompting; the LLM brain is easily swapped and memory is usually handled by default on platforms.
- Every action online is a request/response via APIs (GET = ask for information; POST = send information). Agent tools are APIs wrapped with natural-language schemas so the LLM knows what the tool does, what input it needs, and when to use it.
- Two agent categories: conversational (humans chat directly via website/WhatsApp/phone/Instagram) and automated (triggered by events like form submissions or schedules, no human step).
- Four real-world use cases: co-pilots (role-specific, e.g. customer support), lead generation/appointment setting (most valuable right now), research agents (lead qualification briefs), and personal assistants (dominated by big tech — OpenAI Tasks, Google/Gemini, Apple Siri — not the opportunity for small builders).
- Multi-step agent tasks are still often unreliable and typically need human supervision for complex workflows.
- Monetization path: sell AI services to small businesses via education, consulting, or implementation; get first clients through warm outreach or a content flywheel (post what you learn into a community to build credibility).

## Exact business model discussed
AI automation agency (AAA) model: build and sell AI agents to small businesses (creator cites businesses with 5–500 employees as the target; small businesses create 62% of US jobs per Kevin O'Leary). Three service types: (1) education — workshops, training, courses explaining AI in simple terms; (2) consulting — analyzing operations and showing where AI saves time/makes money (AI strategist); (3) implementation — building and deploying AI systems (agents) for clients. Morningside AI (creator's agency) does all three: AI education/upskilling, AI strategy/roadmap consulting, and AI development services. Getting customers: warm outreach to people you already know, or a "community content flywheel" (post tutorials into a community → instant audience + credibility → clients). Creator claims over $5 million in revenue from these AI services in two years and 450,000+ YouTube subscribers.

## Customer
Small businesses — specifically US businesses with 5–500 employees making between $500,000 and $10 million per year (1.7 million such businesses in the US alone, creator-stated). Creator says big consulting firms ignore these smaller businesses, yet they have money to invest and are "starving" for AI services (education, consulting, implementation). ## Problem
Businesses get far more inbound leads than they can manually qualify; many leads are unqualified (wrong industry, too small) and arbitrary rules-based filtering leaves money on the table. Sales reps are unprepared for calls and customer support is inconsistent. Customers contacting businesses via website contact forms face delays and may not reach a human, so they drop off. Small businesses know they need AI to stay competitive but don't have time to learn it themselves and big consulting firms ignore them.

## Fulfillment

- Relevance AI: build custom tools (function + API + natural-language schema), connect tools to agents, set core instructions/prompt, pick model (GPT-4o Mini used for speed/cost; O3 mini suggested for strategy steps), share tools/agents via URL or publicly with employees/clients.

## Exact tactics
- Plan builds on a Figma/FigJam board first (tools, agent, flow) so the team/client agrees on the build before building.
- Tool pattern: function → API wrapping → natural-language schema; write clear input descriptions ("this is what the tool does") so the agent knows when to use it.
- Relevance AI build order: tool(s) first (company researcher, prospect researcher, pre-call report), then agent with core instructions referencing tools by name, set tools to "auto run," pick model.
- n8n lead qualification: form trigger → HTTP POST to Relevance AI API (JSON body with expression-mapped company URL) → AI tools agent classifies qualified/not → route to Gmail notification (qualified, split SAS vs agency) or rejection email (unqualified).
- VoiceFlow: knowledge base from FAQ file; KB search step saves chunks to a variable; intent classifier LLM outputs a label (ask a question / get a quote / other); condition router; custom API tool via HTTP request (Bearer auth, content-type application/json); capture lead with validation/retry loop; deploy widget + Twilio number.
- Avoid overusing punctuation in VoiceFlow voice messages (causes unnatural pauses); confirm summaries with yes/no before routing; add no-match/reprompt fallback handling.
- Agentive: clone Relevance tools via OpenAPI schema; set up AirTable webhook (personal access token, Bearer header, application/json body); publish agent; deploy to WhatsApp via Facebook Business Manager with a non-personal phone number; use transcripts to debug tool calls/inputs/outputs and check token cost.
- Monetization: education → consulting → implementation ladder; start with warm outreach or content flywheel; free School community course for building 5–10 more agents to reach "foundational knowledge" in 2–3 months.

## Mistakes / warnings
- Multi-step agent tasks are "often unreliable" and typically need human supervision for complex workflows (stated directly).
- VoiceFlow knowledge base still showed 3.5 Haiku even after model selection (creator noted it as something to double check — possible platform quirk).
- VoiceFlow: this basic build is "nowhere near representative" of production-grade; production assistants need far more fallbacks, reprompts, and no-match edge-case handling.
- Knowledge base answer asked a follow-up question at the end, which breaks a yes/no flow — fix prompt to say "don't ask another question" or add a looping mechanism.
- Relevance AI API body/schema construction can feel "super fiddly."
- Lead capture extraction: prompt must output only "retry" when name/phone missing/invalid; strip newlines; extract phone number only.
- WhatsApp via Agentive: messages don't come back instantly (deliberately feels human).
- WhatsApp business account cannot use your personal WhatsApp number — need a spare SIM or a friend's number without WhatsApp; Facebook Business Manager required (free).
- Creator repeatedly states no sponsorship for any tool shown ("not getting paid a dime").
- The video is a tutorial, not a business case study: no verified client revenue, conversion rates, or pricing for delivered agents.
