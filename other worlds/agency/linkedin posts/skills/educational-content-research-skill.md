# Skill: Educational Content Creation (Research-Driven)

## Purpose
Create original, purely educational LinkedIn content (text posts and carousels) that drives profile views through educational value — not sales pitches, not income claims, not face-based authority. Every piece of content is grounded in real research and teaches a reusable framework.

## When to Use
Every time you create educational content for LinkedIn — text post or carousel. Do not skip the research phase.

---

## Phase 1: Research Protocol (Mandatory)

### Step 1: Dispatch two research agents in parallel

**Agent A — Web Search Researcher**
- Conduct web searches across 6+ categories relevant to the topic
- Fetch and read each candidate page to confirm it's real, current (2025–2026), and substantive (frameworks, decision matrices, scoring systems, statistics — not superficial tips)
- Target: 20+ references

**Agent B — Social Media Scraper**
- Search LinkedIn, Reddit, and X (Twitter) for relevant threads, posts, and articles
- Gather real community perspectives, tool comparisons, failure stories, best practices
- Target: 20+ references

### Step 2: Self-check (MANDATORY — do not skip)

Before reporting back, each agent MUST:
1. Count every reference found
2. Ask: "Is this 20?"
3. If fewer than 20, do MORE searches until 20+
4. Report back with: "I have verified I have X references (target: 20+)."

### Step 3: Collect deliverables
- `research-web-search.md` — web references with URLs, dates, key findings, quotes
- `research-social-media.md` — social media references by platform with URLs, key findings, quotes

---

## Phase 2: Content Rules (Non-Negotiable)

| Rule | Requirement |
|------|-------------|
| Purely educational | Teaches a framework or concept, not a product or service |
| No sales pitch | No "DM me to work with me," no "limited slots," no "book a call" CTAs in discovery mode |
| No income claims | No "$10k/month in 90 days," no unverified revenue figures |
| No face | No photos of people in any slide or post |
| Not niche-tied | Not tied to insurance broker research unless specifically about insurance brokers |
| Original framework | Build a layered system with scoring/decision logic, not generic "5 tips" posts |
| Actionable today | Reader can apply it immediately without buying anything |

---

## Phase 3: Framework Creation

### Build a layered decision framework (not just tips)

A world-class educational post teaches a **framework**, not a list. Structure it as:

**Layer 1: Worth it?** (Priority scoring)
- Score each candidate 1–5 on 3–5 factors
- Define score ranges (e.g., 11–15 = automate now, 4–6 = fix manually)

**Layer 2: Ready?** (Readiness scoring)
- Score 1–5 on documentation, rules-based, stability, stakeholder alignment
- Define what makes something "ready" vs "not ready"

**Layer 3: Which tool?** (Decision matrix)
- Match profile to tool (technical capacity × volume × use case)
- Include pricing at scale where possible

**Layer 4: Measure it** (ROI)
- Formula: ((Benefits − Costs) ÷ Costs) × 100
- Include benchmarks from research

**Anti-patterns:** What NOT to do (explicit list)

**First-build rule:** Run alongside manual process for 2 weeks before cutover

## Phase 4: Content Formats

### Text Post Structure

| Element | Requirement |
|---------|-------------|
| Hook | First line stops the scroll. Under 150 characters / 2–3 lines before "see more" |
| Body | One idea per paragraph. 1–3 lines per paragraph max. Short sentences (under 20 words) |
| Line breaks | Every 1–3 lines. No walls of text |
| CTA | Low-friction question, not a pitch. "Comment X" or "Which process feels most broken?" |
| Hashtags | 0–3, relevant only |
| Read-aloud check | If you stumble on a sentence, cut or split it |
| No em dashes | Use hyphens or colons |

**Text post outline:**
1. Hook (1–2 lines)
2. The problem/trap (2–3 lines)
3. The framework (3–5 short paragraphs, each teaching one thing)
4. Examples with specifics (numbers, names, scenarios)
5. CTA (question, not pitch)
6. Hashtags (0–3)

### Carousel Structure (6–9 slides)

| Slide | Purpose | Content |
|-------|---------|---------|
| 1 | Hook | Stop the scroll. One bold claim + stat |
| 2 | The Trap | Wrong way vs right way (visual comparison) |
| 3–6 | Framework layers | One layer per slide. Score/threshold on each |
| 7 | Anti-patterns | What NOT to do (red-tinted) |
| 8 | CTA | Low-friction engagement question |

**Carousel rules:**
- One idea per slide
- Strong hook on slide 1
- CTA on final slide
- No faces, no stock photos
- Text + icons + simple diagrams + screenshots only

## Phase 5: Before Posting Checklist

- [ ] Hook stops scroll in first line?
- [ ] Every sentence under 20 words (mostly)?
- [ ] Line breaks every 1–3 lines?
- [ ] Read out loud without stumbling?
- [ ] No corporate-speak (synergy, leverage, transform, game-changer)?
- [ ] No em dash?
- [ ] CTA is a question, not a pitch?
- [ ] 0–3 relevant hashtags max?
- [ ] Teaches one specific framework?
- [ ] No income claims?
- [ ] No face in any slide or post?
- [ ] References real research (cited at bottom)?
- [ ] Named something specific (tool, amount, hours, scenario)?

## Reuse Instructions

To create a new educational post:

1. Dispatch Agent A (web search) and Agent B (social media) with the topic
2. Wait for both to self-report "I have verified I have 20+ references"
3. Read both `research-web-search.md` and `research-social-media.md`
4. Synthesize themes: frameworks, scoring systems, anti-patterns, tool comparisons, ROI benchmarks
5. Build an original layered framework (not generic tips)
6. Write the text post OR carousel slide spec using Phase 4 format
7. Run Phase 5 checklist
8. Add Phase 6 research sources
9. Save to `drafts/week-N/` with descriptive filename
