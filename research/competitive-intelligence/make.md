# Research Report — Make (https://make.com/)

**Category:** Workflow automation platform  
**Date inspected:** 2026-10-27  
**Source:** Homepage content fetch (observed; not a screenshot). Homepage-level only.

## Positioning & value proposition
- Headline: "Build and manage AI agents and automations in one visual landscape"
- "Connect any app, data source, or AI model." Build via prompting, drag-and-drop, or AI chat (Claude, ChatGPT, etc.).
- "One AI Automation platform" — every team builds, with visibility and control.

## Target audience
"500,000+ teams build with Make," from startups to global enterprises. Builder roles: Executive, Change leader, Builder. Vertical solution pages: Marketing, Sales, Operations, IT, Finance, Customer Experience, Productivity, People/HR.

## Navigation (top)

Product: Overview, Integrations, Maia AI assistant, AI agents, AI Automation, Agentic automation, Make Grid, MCP server, Status, Idea exchange.
Solutions: Marketing, Sales, Operations, IT, Finance, Customer Experience, Productivity, People.
Resources: Templates Library, Make AI apps, Help center, Blog, Success stories, How-to-guides, Make Academy, Make Community, Webinars, Make Events.
Company: About us, Careers, Contact us, Press, legal.
Partners: Hire an expert, Become a partner.

## Offerings
Workflow Builder (prompting, drag-and-drop, MCP); Observability; Custom code (JavaScript/Python); MCP Server; AI Agents (goals, tools, limits, reasoning view); Governance; 3,500+ native app connections + custom API integrations.

## Free tools / templates / interactive features
- "Try it free" / "Try Make free" entry points; "No credit card required"; "No time limit on free plan."
- Templates Library.
- FAQ: free plan includes enough credits and active scenarios to build and run real automations.

## Developer resources
3,500+ apps out of the box; custom integrations to anything with an API; custom code (JavaScript/Python); MCP server; "Make AI apps" integrations category.

## Community features
Make Community (community.make.com/); Make Academy (academy.make.com/); Idea exchange; Help center; Webinars; Make Events.

Free tier available ("No credit card required", "No time limit on free plan"). Paid plans scale; Enterprise via sales. No specific dollar prices visible.
