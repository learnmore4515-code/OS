# Research Report — Vercel (https://vercel.com/)

**Category:** Developer-first technology / infrastructure platform  
**Date inspected:** 2026-10-27  
**Source:** Homepage content fetch (observed; not a screenshot). Homepage-level only.

## Positioning & value proposition
- Headline: "Agentic Infrastructure"

- Supporting: "Build agents on infrastructure that thinks like them."

## Target audience
Coding agents and teams shipping apps, agents, and customer platforms. Evidence cites Notion, Zapier, Mintlify.

## Navigation
No traditional nav bar; inline links: "Deploy now" (/new), "Talk to sales" (/contact/sales), "Learn more" (/backends, /agents, /sandbox), Vercel setup guide (/get-started.md), Vercel Drop (/drop), deploy-without-logging-in docs, brand asset catalog, feedback form.

## Offerings
Agentic Infrastructure; Durable Orchestration; Sandboxed Environments; AI Model Gateway; Fluid Compute; Global Delivery; Deployment Environments; Serverless Functions; WAF; Tenant Isolation; Domain Management; Custom SSL; Preview URLs; Python backends/queues/daemons; agent stack; Sandbox; API, CLI, MCP, Skills; 400+ models.

## Free tools / interactive features
- `vercel deploy --temporary` (deploys without sign-up).
- Vercel Drop (drag a static site folder to deploy).
- Brand asset catalog (SVG/PNG downloads).

## Developer resources
API, CLI, MCP, Skills; docs (/docs/deployments/deploy-without-logging-in); agents can "open PRs."
