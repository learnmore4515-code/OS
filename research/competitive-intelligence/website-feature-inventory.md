## Key takeaways for LeoPisha

1. **Resource library is a differentiator.** Make (Academy, Templates Library, Blog, How-to, Webinars, Events) and LangChain (Academy, docs, blog, changelog, newsletter) show that a coherent education pillar is common among credible automation/AI companies. LeoPisha currently has ONE resource page and no blog — a clear gap.

2. **Templates + community drive distribution.** n8n, Zapier, Make all have template libraries and expert/partner directories. LeoPisha has no public workflow templates, no developer resources, no community — another clear gap that also limits SEO/distribution.

3. **Quantified case studies build trust.** Every reference company publishes named customers with metrics (hours saved, $, orders/day). LeoPisha honestly has none yet — the right move is to keep the honest placeholder until permissioned client work exists, then publish quantified case studies.

4. **"Hire an expert / partner" programs are a services channel.** n8n (experts.n8n.io) and Make (hire an expert / become a partner) convert platform users into services buyers. LeoPisha (a consultancy) should consider an expert directory or partner referral path as it grows.

5. **Not everything needs replication.** Zapier has no community or free tools on its homepage and is still a major player. Thoughtworks (pure consultancy) has no free tier or templates. LeoPisha should pick a small set of high-value assets, not copy every pillar.

6. **Developer content = authority + SEO.** n8n (llms.txt, GitHub stars, API/MCP), Vercel (docs/API/CLI), LangChain (docs, Academy) show technical content builds credibility and search visibility. LeoPisha's n8n expertise is under-documented publicly.

7. **Free low-friction entry wins.** Vercel's "deploy without login" and Make's "free tier, no credit card" reduce friction to first value. LeoPisha's only conversion is a Calendly booking call — a relatively high-friction ask for cold visitors.
