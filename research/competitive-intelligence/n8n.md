# Research Report — n8n (https://n8n.io/)

**Category:** Workflow automation platform (open-core, self-hostable or cloud)  
**Date inspected:** 2026-10-27  
**Source:** Homepage content fetch (observed; not a screenshot). Homepage-level only.

## Positioning & value proposition
- Headline: "Build the agent. Understand its workflow."
- Sub-headline: "n8n is the platform for agents and workflows you can follow. Open any step, see what it does, and explain to anyone who runs it."
- Supporting: "The USB-C for your AI stack"; "See + understand + trust your agents"; "Connect any model, see every decision, and add human approval when needed."
- Claims 500+ native integrations, any API via HTTP, MCP support for agents/coding assistants.

## Target audience
Developers, IT, DevOps, Security, Sales teams; teams of any size including Fortune 500. Claims "Join 250k+ developers in our community."

## Navigation (top)
Product, Use cases, Docs, Community, Enterprise, Pricing, Sign in, Get started.

## Offerings
AI workflow automation platform with visual builder + code drop-in; human-in-the-loop approvals; self-host (Docker/on-prem) or hosted (n8n.cloud); observability (audit logs, SIEM, workflow history, alerts, dashboards); security (SSO/SAML, LDAP, encrypted secrets, RBAC); developer experience (Git-based control, isolated environments, workflow diffs); AI governance (guardrails, evaluations).

## Free tools / templates / interactive features
- Refund-request workflow demo (click-through showing steps: lookup order → Slack approval → refund/ticket paths).
- Example workflows: Process invoice, Knowledge assistant, Daily News Digest.
- Replay past runs / mock data; re-run single broken steps.
- `llms.txt` for machine-readable content.

## Developer resources
Docs at /docs; HTTP API + MCP; Git-based control, workflow diffs, isolated environments; GitHub (claimed Top 50, 208.7k stars).
